# Sistema de Gestão Hospitalar 🏥
Sistema de gestão hospitalar desenvolvido em Java com interface gráfica para cadastro de pacientes, registro de óbitos e consultas ao banco de dados.
## 📋 Sobre o Projeto
Este projeto foi desenvolvido como atividade acadêmica para a disciplina "Programação em Java" do Professor Mozar. O sistema oferece uma interface intuitiva para gerenciamento básico de dados hospitalares, permitindo o cadastro de pacientes e controle de registros de óbito.
## ✨ Funcionalidades
 - 👤 Cadastro de Pacientes: Inserção completa de dados (nome, idade, CPF, etc.)
 - 💾 Armazenamento em Banco de Dados: Persistência segura dos dados.
 - ⚰️ Registro de Óbitos: Sistema para registrar falecimentos
 - 📊 Listagem de Pacientes: Visualização de todos os pacientes cadastrados
 - 🖥️ Interface Gráfica: Sistema simples e fácil de usar
## 🛠️ Tecnologias Utilizadas
 - Linguagem: Java
 - Banco de Dados: SQLite
 - IDE: VS Code com extensões de Java
